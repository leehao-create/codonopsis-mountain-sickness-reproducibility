# Molecular docking

This directory contains the final reviewer-response rerun using NR3C2 PDB 2AA2 and catalytic-domain MMP9 PDB 1GKC, all receptor/ligand inputs, prepared structures, Vina configurations, logs, candidate poses, redocking poses and RMSD results. It excludes the installed 1.7 GB Conda environment and all earlier docking runs.

Create and activate the environment from `environment.yml`, change to this module directory, and run `scripts/run_all.sh`. Config paths are repository relative. The final numerical results are the frozen CSVs and pose files already under this directory.
